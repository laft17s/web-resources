# 🔘 Futuristic Buttons Showcase

A premium collection of futuristic button components designed with flat design principles, neon accents, and smooth transitions. These buttons are framework-agnostic and ready for any modern web project.

![Buttons Preview](https://img.shields.io/badge/Design-Futuristic-cyan?style=for-the-badge)
![Style](https://img.shields.io/badge/Style-Flat%20Design-blueviolet?style=for-the-badge)

## ✨ Button Models

This collection includes 4 distinct geometric models:

1.  **Rounded**: Classic 50px rounded corners with a smooth hover glow.
2.  **Squircle**: Mathematical squircle shape for a premium, high-end aesthetic.
3.  **Rectangular**: Sharp, industrial design with a bold accent border.
4.  **Cyber**: Asymmetrical geometry using custom `clip-path` for a unique futuristic experience.

## 🚀 Features

- **Color Variants**: Includes Primary, Success, Warn, Danger, Info, Contrast, and Link variants.
- **Flat Design**: Clean and modern aesthetics without unnecessary clutter.
- **Neon Accents**: Vibrant colors that pop against dark backgrounds.
- **Smooth Transitions**: Cubic-bezier animations for a premium feel.
- **Code View**: Integrated modal to copy HTML and CSS snippets instantly.
- **Responsive**: Designed to work perfectly on all screen sizes.

## 🛠️ Usage

1. Open `buttons.html` in your browser.
2. Explore the different button models and their hover effects.
3. Click **"View Code"** to see the implementation details.
4. Copy the **HTML** and **CSS** and paste them into your project.
