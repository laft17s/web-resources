# 🎴 Futuristic Cards Showcase

A premium collection of futuristic card components designed with flat design principles and glassmorphism effects. These cards are framework-agnostic and ready to be integrated into any modern web application.

![Cards Preview](https://img.shields.io/badge/Design-Futuristic-cyan?style=for-the-badge)
![Style](https://img.shields.io/badge/Style-Flat%20Design-blueviolet?style=for-the-badge)

## ✨ Card Models

This collection includes 4 distinct geometric models:

1.  **Rounded Vision**: Classic 24px rounded corners for a smooth, modern look.
2.  **Squircle Core**: A premium mathematical squircle shape for a high-end feel.
3.  **Industrial Edge**: Sharp, rectangular design with a bold accent border for a technical aesthetic.
4.  **Cyber Nexus (Free Art)**: Asymmetrical geometry using custom `clip-path` for a unique futuristic interface.

## 🚀 Features

- **Flat Design**: Clean, modern aesthetics without unnecessary shadows or textures.
- **Glassmorphism**: Subtle background blur and transparency for depth.
- **Interactive**: Smooth hover transitions and animations.
- **Code View**: Integrated modal to copy HTML and CSS snippets instantly.
- **Responsive**: Grid-based layout that adapts to any screen size.

## 🛠️ Usage

1. Open `cards.html` in your browser.
2. Explore the different card models.
3. Click **"View Code"** to see the implementation details.
4. Copy the **HTML** and **CSS** and paste them into your project.
