# 🪟 Futuristic Modals Showcase

A premium collection of futuristic modal components designed with flat design principles, glassmorphism, and smooth transitions. These modals are framework-agnostic and ready for any modern web project.

![Modals Preview](https://img.shields.io/badge/Design-Futuristic-cyan?style=for-the-badge)
![Style](https://img.shields.io/badge/Style-Flat%20Design-blueviolet?style=for-the-badge)

## ✨ Modal Models

This collection includes 4 distinct geometric models:

1.  **Rounded Vision**: Smooth 32px rounded corners for a friendly, modern feel.
2.  **Squircle Core**: Mathematical squircle shape for a high-end, premium aesthetic.
3.  **Industrial Edge**: Sharp, technical design with a bold top accent border.
4.  **Cyber Nexus (Free Art)**: Asymmetrical geometry using custom `clip-path` for a unique futuristic experience.

## 🚀 Features

- **Flat Design**: Clean and modern aesthetics without unnecessary clutter.
- **Glassmorphism**: High-quality background blur and transparency.
- **Smooth Transitions**: Scale and opacity animations for a premium feel.
- **Code View**: Integrated meta-modal to copy HTML and CSS snippets instantly.
- **Responsive**: Designed to work perfectly on all screen sizes.

## 🛠️ Usage

1. Open `modals.html` in your browser.
2. Click **"Preview Modal"** to see the design and animations.
3. Click **"View Code"** to see the implementation details.
4. Copy the **HTML** and **CSS** and paste them into your project.
