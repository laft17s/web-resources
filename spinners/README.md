# 🌀 CSS Spinners Showcase

A premium collection of modern, lightweight, and copy-paste ready loading spinners built with pure CSS. Designed for high performance and seamless integration into any web project.

## ✨ Features

- **Pure CSS**: No external dependencies or heavy libraries.
- **Modern Aesthetics**: Sleek designs with smooth animations and glassmorphism effects.
- **One-Click Code**: Unified "View Code" popup to easily copy HTML and CSS.
- **Responsive**: Works perfectly across all devices and screen sizes.
- **Dark Mode Optimized**: Built with a deep, modern color palette.

## 🚀 Getting Started

Simply open `spinners.html` in your browser to explore the collection.

### Usage

1. Browse the available spinners.
2. Click **"View Code"** on any spinner card.
3. Copy the **HTML** and **CSS** snippets.
4. Paste them into your project!

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Advanced animations, gradients, and variables.
- **JavaScript**: Interactive modal and code extraction logic.
- **Google Fonts**: 'Inter' for clean typography.
